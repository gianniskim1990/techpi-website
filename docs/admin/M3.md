## 1. What M3 does

The copy of the 8 website pages (Home, Work, Capabilities, EU Projects, About, Contact, Privacy, Cookies) is managed
through the custom admin in English and Greek, with each page's search title and description. For each page the admin
loads the real content from GitHub, edits it in both languages, validates, detects conflicts and saves a draft to the
page's own branch `cms/pages/<key>` with **one** draft pull request into `feat/techpi-admin-m3-website-pages`; an English
save and a later Greek save update the same pull request. Saving never changes techpi.eu. "New page" and Publish are
disabled. The Website pages section reads live from GitHub (the earlier snapshot table is gone when connected).

## 4. Editable and locked

- **Editable, in both languages:** every text field of each page, including list items (which can be reordered),
  headings broken over lines, labels and buttons, and the search title and description.
- **Locked everywhere:** URLs, the page key, the structure (the same keys and the same number of items in every list:
  the components lay them out, so items cannot be added or removed), and the line count of each headline per language.
- **Locked values:** Contact's town; the EU Projects non-endorsement disclaimer; the legal page titles (h1), section
  anchors, version date and its displayed text, the generated operator-address and registration blocks, and the
  Hellenic DPA's address.
- **Rules (admin, Worker and build alike):** plain text (no line breaks, `<` `>`, links or markup outside the legal
  pages), no draft markers, length limits; the search title names TechPi in at most 70 characters, the description has
  70 to 200 (the SEO validator's limits); "TechPi" and "pigiota314" stay in the lines that state their relationship (Home
  evolution heading, About heading, Work's earlier-work heading); no certification, endorsement, guarantee or result
  claims in the EU Projects copy or teaser.

## 5. Legal-content safeguards

- Values that `legal.ts` interpolated are **references** in the files, resolved by the build: `{{email}}` and
  `{{phone}}` (links built from `site.ts`), `{{operator.name}}`, `{{operator.town}}`, `{{path.privacy}}`,
  `{{path.cookies}}` and `{{url.cloudflarePrivacy}}`, `{{url.cloudflareCookies}}`, `{{url.dpa}}`, `{{url.dpaComplaint}}`.
  The operator's address and the GEMI/VAT line are `{ "dynamic": ... }` blocks generated from `site.ts`. No file holds a
  copy of a fact.
- Per section, every reference must stay (it can move within the text, not be added or removed); unknown references,
  typed-out emails, phone numbers, registration numbers, the street, `mailto:` and `tel:` are refused.
- Links only as `[text]({{reference}})`; `**bold**` and `` `code` `` must be balanced.
- The verified Google Search Console statement must stay word for word; the operator's name (including the Greek
  declined form "Ιωάννη Κιμούντρη", which the source writes literally) must stay in its section; the retired claims are
  refused (the same list as `scripts/content/validate-legal.mjs`; a test checks that they agree).
- Legal-page pull requests state that **a technically valid change is not a legally approved one**: every policy change
  needs the owner's review before it is merged. The editor says the same.
- The legal validator was **not** relaxed: what it pins (operator name, street, mailto link, GEMI/VAT, one version date,
  the Search Console statement, retired claims, h1) is fact, not editorial wording, and the admin locks or protects
  exactly those things. No other validator pinned page wording, so none needed changing.

## 8. Local test with real GitHub (owner)

Nothing below has been run. In the local, git-ignored `admin/wrangler.local.jsonc`, change `CONTENT_BASE_BRANCH` to
`feat/techpi-admin-m3-website-pages` (pushed with this pull request). `.dev.vars` is not touched. Then in `admin/`:

```bash
node scripts/check-local-config.mjs --github
npm run build
npx wrangler dev --config wrangler.local.jsonc
```

Open `http://127.0.0.1:8787/#/pages`. Loading is read-only. Each **Save draft** creates or updates one public draft
pull request for that page; close them without merging when the test is done. Do not merge a legal-page draft without
reviewing the policy change.

## 9. Deferred and limitations

- The shared case-study labels and closing line, and the shell labels, are not in the admin.
- The search preview approximates how search engines shorten titles and descriptions.
- Not built: new pages, publishing, a preview of the draft site, media, SEO overview, settings.
